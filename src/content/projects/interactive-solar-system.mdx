The background of this site isn't a picture — it's a coordinate system. Every
celestial body is laid out along the page's scroll height, so scrolling down is
literally a trip outward from the Sun toward the Kuiper Belt.

## The journey model

Each body has a `journeyPosition` in the range `[0, 1]`. Its document Y position
is simply:

```ts
const documentY = journeyPosition * docHeight;
```

A per-body `parallaxSpeed` then offsets it against the scroll position, so
farther planets drift into view later. Repositioning anything in space is a
matter of editing two numbers — never pixel values.

## Why not React state?

Per-frame scroll updates never touch React state. Instead the components keep
their data in refs and mutate `element.style.transform` directly inside a
`requestAnimationFrame` loop. React only re-renders when DOM *nodes* are added
or removed (spawning a comet, for example).

> The result: smooth 60fps parallax even with dozens of moving objects on screen.
